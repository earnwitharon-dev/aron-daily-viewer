# ARON Daily Viewer

Mobile-friendly static Dailymotion viewer shell for GitHub Pages.

## Features
- Paste a Dailymotion URL or video ID
- Mobile and desktop responsive layout
- Fullscreen + cinema mode
- Local recent-history list
- Shareable direct links such as `?v=xbf1yae`
- Editable Dailymotion Player ID

## Important
Dailymotion controls the embedded player, availability, regional restrictions, and advertising. This site does not remove or bypass Dailymotion-served advertising.

Dailymotion's current embed system uses a valid Player ID. Replace the demo Player ID with your own Dailymotion Studio Player ID for long-term use.

## Deploy
Run `DEPLOY_TO_GITHUB.ps1` in Windows PowerShell.
